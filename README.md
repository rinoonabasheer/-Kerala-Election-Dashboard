# 🗳️ Kerala Election 2026 Dashboard (Excel)

An interactive Excel dashboard that analyzes the Kerala Assembly Election 2026 results by alliance, party, district and gender.

## 🎯 Objective
To show which alliances and parties won the 140 seats, how winning margins differ across parties, and how results are spread across districts and genders.

## 📌 Key Numbers
| Metric | Value |
|---|---|
| Total seats | 140 |
| UDF | 102 seats (73%) |
| LDF | 35 seats (25%) |
| NDA | 3 seats (2%) |
| Male winners | 129 |
| Female winners | 11 |

## 🔍 Key Insights
- UDF won the largest share, with 102 of 140 seats.
- LDF won 35 seats and NDA won 3.
- Average winning margin varies a lot by party. KEC(J) has the highest average margin, followed by IUML.
- Only 11 of the 140 winners are women, compared with 129 men.
- Alliance wins differ from district to district, shown in the district-wise line chart.

## 🧩 Dashboard Features
- **KPI cards:** total seats and seats won by LDF, UDF and NDA
- **Column chart:** average winning margin by party
- **Pie chart:** seat share by alliance
- **Line chart:** alliance-wise wins across districts
- **3D column chart:** winners by gender
- **Slicers:** Party, District, Alliance and Gender, which filter every chart at once
